# Data files

The complete project archive in [Releases](https://github.com/limerun/malopolska-vineyard-suitability/releases/tag/v1.0) contains the input data, intermediate layers and results. Extract the archive and open `project.qgz` without moving the `data` folder.

Large data files are stored in Releases rather than Git history. `manifest.csv` lists the files and their SHA-256 checksums.
